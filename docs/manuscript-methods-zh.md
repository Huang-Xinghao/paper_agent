# Methods

Paper-Agent 是面向电池研究的知识增强科研系统，通过文献证据提取、领域知识检索与分阶段任务编排，将研究目标转化为可执行实验和学术论文。系统支持自主运行与专家参与两种模式，并分别通过流程内评审和独立基准评价实现产物修订与质量评估。

## 1. 外部文献提取

系统结合本地文献与 OpenAlex、Semantic Scholar 和 arXiv 检索相关研究，并通过 MinerU 对纳入范式库的论文进行全文解析，保留正文、公式、表格、图注及原始页码。语言模型将解析内容组织为论文、研究思路和实验三类实体，分别表征研究问题与主要结论、核心方法机制，以及实验设计与结果。关键描述关联来源页码，以支持证据追溯。

在单篇提取基础上，系统进一步识别论文间的方法共享、问题关联、扩展、冲突及有文献依据的思路来源关系。每次从已有文献中选择至多 8 篇进行比较，生成的关系须包含双方笔记中的原文摘录与解释，并通过实体类型和摘录一致性校验。不生成假设性方法迁移关系，文献报告的实验与系统实际执行的实验分别记录。

## 2. 电池资源库与范式库

系统构建互补的电池资源库与研究范式库。资源库覆盖电芯和电解液研究，按照数据集、输入表示与建模方法组织领域知识。电芯资源包含物理特征、时序和图像表示及相应建模规范；电解液资源涵盖分子性质、分子动力学模拟和实验电导率数据，以及分子结构、配方组成和温度等输入表示。数据说明与实际数据访问分离，候选数据通过字段及样本检查确认任务适用性。

范式库以论文、思路和实验为基本实体，通过带证据的类型化关系构成研究知识图谱，并按研究领域、任务、方法、数据类型和应用场景进行索引。研究阶段通过文本检索获取相关资源与范式，将数据可用性、观测时点、方法假设和已有证据共同纳入方案构造，为研究问题定义、方法选择与实验设计提供约束。

## 3. 科研工作流

Paper-Agent 采用确定性控制器编排 11 个阶段：文献调研、数据发现、思路生成、研究细化、实验规划、实验实现与执行、论文规划、图表生成、论文写作、编译及评审修订。各阶段配置专门的任务指令与工具集合，并通过持久化产物传递研究上下文，将研究假设逐步落实为实验计划、代码、结果和论文。

实验任务以显式依赖图组织，每个任务声明执行入口、上游依赖与预期输出。仅当依赖满足时启动任务，并在进程成功退出且输出校验通过后确认完成；失败任务返回实验阶段进行局部修复。控制器保存节点状态、执行回执与中间产物，支持中断恢复及有效结果复用。论文中的定量证据由已完成实验提供，随后进入图表组织、稿件生成和评审修订。

## 4. 人机协作

专家模式在主要阶段设置审阅检查点，提供产物摘要及针对当前研究取舍的问题。专家可通过文字反馈、直接编辑或确认现有产物参与研究，反馈由当前阶段吸收并形成修订结果，经校验后传递至下游。干预内容可涉及研究假设、数据适用性、实验优先级与图表表达。

系统保存专家反馈及确认版本的文件哈希，使后续阶段与已审阅内容保持一致。专家确认仍受实验完成条件与产物校验约束；修改结果文件不替代实际实验执行。该机制将领域判断嵌入阶段间的决策过程，同时保留工作流的可追溯性与可恢复性。

## 5. 基准评价

独立基准平台为 Paper-Agent、AI-Scientist-v3、Codex CLI 和 Claude Code 提供共同的研究任务与数据访问接口。当前任务基于 MATR 数据，研究利用前 100 个循环内可获得的测量预测剩余循环寿命。任务要求明确寿命终点与删失处理、按电芯划分样本、仅在训练数据上拟合预处理，并提供简单基线、重复评估及适用条件下的充电协议泛化分析。各系统自主设计实验并提交代码、预测结果、图表和最终论文。

论文质量采用 AI Scientist 的五审稿人加 Area Chair 协议评价。五次独立模型调用依据统一规范评估论文文本，数值评分按对应字段取算术平均并取整，同时保留未取整均值；接收决策由 Area Chair 汇总产生。Overall 采用十分制，原创性、质量、清晰度、重要性、可靠性、呈现和贡献采用四分制，审稿置信度采用五分制。该评价衡量统一评审条件下的论文质量；平台未设置封闭测试集，各系统的预测性能由其自行设计的实验报告。

图像采用 PaperBanana 有参考图协议，针对相同方法或数据的生成图与人工参考图，分别评价忠实性、可读性、简洁性和美观性。生成图胜、参考图胜及平局分别赋值 100、0 和 50，综合判定优先考虑忠实性与可读性，再考虑简洁性与美观性。论文与图像评分分别报告，评测保存输入指纹、裁判配置与原始响应，以支持结果核查。

## 6. 文献图像辅助设计

系统复用文献解析结果，根据图注锚点与空间邻接关系合并多子图，并通过架构、流程和示意等图注语义筛选参考图。图像与原始图注、论文标识及页码共同保存。绘图阶段采用图注 BM25 检索与中英文术语映射，获取与目标模块和表达需求相关的候选图。

参考图用于辅助面板组织、信息层级与连接关系设计，具体科学内容由当前研究方案和实验结果确定。架构图通过图像生成或程序绘制实现，定量结果图依据实际实验数据绘制。最终图像经视觉检查，并与稿件引用及交付文件核对，保持方法描述、实验结果与视觉表达的一致性。

## 7. 外部评审与修订

系统通过独立模型会话提供思路、代码和论文评审。评审器接收指定产物与评价准则，不继承生成阶段的对话历史，以只读方式输出意见，由生成阶段完成修订与验证。思路评审关注研究价值、新颖性、方法合理性与可行性；代码评审检查数据划分、预处理、标签、指标及对比实验的实现，重点识别信息泄漏和方法实现偏差。

论文修订采用两轮机制。首轮综合检查科学逻辑、证据、引用、图表和排版，并依据问题严重程度指导修改；次轮结合首轮报告与修改记录，逐项核查问题解决情况及新增缺陷。每轮修改后重新编译稿件。流程内评审服务于产物改进，与独立基准评分分别执行；评审意见不替代实验验证。
