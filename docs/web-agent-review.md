# 网页 Agent 展示与协作模式（2026-11-13）

网页工作台展示主控、构思、实验、论文四个持久角色。默认在运行时跟随当前执行角色，空闲时展示完整历史；也可选择某个角色或全部记录。角色切换仅改变查看范围，用户指令仍交给主控。派单、交接、模型输出和工具记录保留角色身份。

`GET /api/projects/{id}` 的 `agents` 字段读取已有角色会话，不创建额外执行记录。当前网页运行的事件用于识别执行角色；本地／HERDR 已提交且尚未消费的任务通过统一执行目录确认，终端运行不会引用旧网页任务的事件。结束或中断后不再显示角色正在执行。

## 修复的模式问题

- 对话输入区与运行设置共用一个模式选择，项目刷新时恢复已保存模式。运行窗口移除打开动画结束后的表单重置，避免快速选择被覆盖；关闭时清理表单，重开时使用当前选择。
- API 请求未指定模式时继承项目设置；网页新项目默认专家模式，显式选择自动模式正常生效。主控构造函数也继承已有模式，worker 不再强制改成自动模式。
- 阶段待审阅时保留当前模式，必须先批准或修订，不能用切换模式跳过审批。
- 讨论完成或修改失败不会覆盖仍待审阅的阶段状态；自动模式中主动修订研究方案形成的待审稿，也显示专用方案审阅入口。
- 自动模式在已授权任务范围内连续推进；专家模式在阶段交付后等待审阅。两种模式都可能遇到需要用户回答的实际阻塞，自动模式不代表跳过明确修订后的重新审批。

## 验证

后端测试覆盖四类请求继承两种模式、新项目默认与显式选择、待审阅状态、角色交接、终端本地／HERDR 任务、自动模式连续派单。浏览器测试覆盖角色查看、实时交接、刷新、移动端、模式同步、方案审阅和任务问答。

测试使用临时项目、模拟模型和浏览器网络拦截；不以真实模型响应、外部评审或科研训练作为验证依据。前端源代码位于相邻的 `paper-agent-web` 仓库，需要与 API 一起更新。
