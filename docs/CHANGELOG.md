## 2026-11-10 — MCP 外部工具管理

- 新增侧边栏 MCP 管理：远程 Streamable HTTP 连接、无认证/Bearer/API Key、分页发现、兼容性说明、工具选择、阶段绑定及最近调用记录。当前配置在单工作台共享。
- 官方 SDK 2.3.0 适配现有 ToolSpec，不改 Agent 框架；阶段开始固定目录，后续新阶段读取最新配置。每次外发重新检查权限和工具定义，停用/撤权影响后续调用。
- 凭据由独立主密钥加密，管理接口不回显；etag 防止旧页面覆盖新配置。默认公网 HTTPS443，DNS 校验后固定 IP 拨号，禁重定向/环境代理；管理员可登记精确端点例外。
- MCP 由 PhaseAgent 按阶段独立加载，不依赖 Wiki；工具结果直接交给阶段 Agent，不自动入库。首版只支持文本/JSON，不开放任意 stdio 启动命令、OAuth、写操作或个人电脑连接器。
- 同日修正初版将 MCP 接入 Wiki 取证的耦合：移除共享取证预算与 external_candidates 输出，恢复 Wiki 原有入口；Wiki 依据包交接不再关闭 MCP。外部结果使用通用的 external_tool_data 标记。
- 增加挂载目录依赖与加密配置安装脚本；本地 Docker 环境把包和密钥放在 E 盘，既有 MinerU/E5 环境继续加载。
- 验证：Windows 相关后端69项、Linux容器新增MCP17项、桌面/手机浏览器2项通过；TypeScript、改动文件ESLint与Vite构建通过。真实 DeepWiki 目录读取成功，真实 gpt-6.1-sol 通过 PhaseAgent 两轮请求调用一次工具并生成研究便笺；测试使用隔离项目，不代表新实验或论文研究结论已验证。
- 解耦修复后验证：Windows 相关后端70项、Linux容器MCP18项通过；TypeScript、MCP前端ESLint和Vite构建通过。本地API已重启加载修复。
- 使用与工程说明分别见 [操作指南](guides/mcp.md)和[技术说明](reference/mcp-management.md)，[开源调研](mcp-research-2026-11-09.md)保留方案依据和后续方向。
- 补充[工程讲解与面试场景](explanations/mcp-engineering.md)：从真实代码的管理/调用链讲解工具发现、模型选择、授权、定义更新、故障定位、网络、身份、异步生命周期及评估，区分现有实现与后续方案，并附官方资料和公开题库来源。

## 2026-11-09 — Wiki 检索与研究依据

- 文献研究、创意生成和研究精炼接入统一取证入口，支持精确标识定位、章节 BM25 与本地多语言 E5 的 RRF 融合、按栏目补读及按需关系导航。
- 每次取证限制3次模型请求、6次 Wiki 工具执行、1次图扩展；最后一轮整理结论，超限不执行。报告撰写复用依据包，关闭该次重复 Wiki 工具入口。
- 依据包记录论文摘录、采用或排除理由、假设、缺口、来源位置与质量记录；程序检查逐字引文、实际已见来源和正文指纹。
- 画布方案修订复用最近依据并复查版本，来源变化时撤下过期证据、摘要和采用建议；人工批准及锁定方案约束继续生效。
- 语义不可用时默认搜索明确降级为关键词检索；支持固定模型身份、内容缓存、环境配置和独立编码进程。
- 固定查询与工程边界验收完成；提交前论文预处理、质量记录、检索、取证交接及模型重试相关回归123项通过。
- 文档按当前检索方案整理为[使用说明](guides/wiki-retrieval.md)和[技术说明](reference/wiki-retrieval.md)。

## 2026-11-07 — Wiki 问题分类与带问题入库

- 区分论文本身的报告问题和入库整理/解析问题，记录证据、影响和使用提醒。论文报告不一致不再直接阻断入库；整理遗漏最多修订一次后可带记录入库。虚构引用、未修正的错误陈述、无效结构仍阻断。
- Paper 正文显示分类问题清单，质量 JSON 保存机器记录；搜索、分页读取、工作流预读均附带问题。论文派生的 Idea/Experiment 沿来源边返回原论文问题。旧条目无报告时显示未检查，不冒充无问题。
- 同轮修订保留论文疑点；误报更正要求理由和原文证据，保留原观察及更正记录。尚未实现问题管理页面或跨次运行的关闭/合并流程。
- 真实验收复用 15 页论文的既有 MinerU 结果与真实草稿，新增三次模型请求，完成带问题入库和五个节点的读取验证。结果及模型误判边界见 [Wiki 文档](wiki.md#使用论文时如何看到问题)。所有写入限独立测试副本。

## 2026-11-06 — 论文入库预处理与证据核验

- MinerU 全文读取后保留版本化原文块、物理页码、原始坐标、章节归属和表格/图片的嵌套图注、脚注。保守过滤页装饰和重复边缘文字，原始块不删除；记录空页、空表格/公式等解析诊断。
- 整理输出增加信息状态与关键陈述证据；程序检查逐字引用和可选数字推导，单独模型请求复核证据支持及原文遗漏，最多一次修订后再检查。理论论文允许明确不适用，不补造实验。
- 先留存每次运行的原文、草稿与复核报告，通过后再写 Wiki 和证据/质量文件；Zotero 跳过签名与文件检查包含新版本、新产物。旧 Wiki 不批量重建。
- 将 GPU 队列的 Linux 文件锁依赖延迟到实际运行队列时加载，避免 Windows 仅导入 Wiki 就因缺少 `fcntl` 失败；不新增 Windows GPU 队列支持。
- 增加独立 MinerU 4.1.7 CPU 环境安装脚本，标准档位模型下载与校验通过后发布环境文件。本地启动脚本加载该环境；venv、模型、缓存和临时目录都放在 E 盘挂载路径，避免把大文件装进 C 盘 Docker 数据层。Docker 残留 socket 故障按既有恢复脚本处理，前后端实际可访问。
- 验证：本轮相关 76 项在 Windows 和 Linux 均通过；Linux 另有 Wiki 工具/图片引用 10 项通过，新增类型兼容后的预处理 11 项通过（有重叠，不累加）；CLI、文档链接和差异格式检查通过。
- 真实验收：《Set Functions for Time Series》完整 15 页 CPU 解析约 361 秒，保留 214 个带坐标块，含 7 个表格和 8 个公式。真实 `gpt-6.1-sol` 完成整理、复核、一次修订、再复核；第二次所有栏目与实体复核通过，但原文反查仍指出重要遗漏，故按契约停止入库，草稿和报告保留在独立测试目录。不能宣称真实论文入库已通过验收。细节和边界见 [Wiki 文档](wiki.md#论文预处理与证据核验)；未修改生产数据、批量重建旧库或实现核心检索。

## 2026-11-06 — Skill 管理与持续文档

### 新增

- 工作台共享 Skill 管理 API，支持创建、编辑、阶段绑定、启停、历史恢复、下载和自建项软删除；前端新增侧边栏管理入口。
- 开发者内置发布号、内容指纹、个人定制修订及基准分别记录。归档见过的内置发布及包内可读资源，更新保留定制，恢复内置后重新跟随发布。
- 新运行按阶段首次模型调用固定 Skill；已开始阶段保持版本，未开始阶段取最新。加载事件记录实际版本，方案修订也接入显式绑定的 Skill。
- 用户操作、技术实现和文档维护目录，以及两仓 PR 文档提示。

### 修复与兼容

- 详情保存采用 `expected_etag` 防止旧页面覆盖，加载最新同步详情缓存及编辑基线；保留冲突草稿，提供下载。
- 兼容旧整任务快照，不重解释既有运行。当前配置仍是工作台共享，不新增项目/用户级隔离。
- 修正移动端内置更新提示和历史抽屉布局，完善保存操作无障碍标签及浏览器回归配置。
- 安装包补入 `skills/release.json`，使源码运行与 wheel 安装都能读取内置发布号。

本轮实现验收记录：后端相关 101 项通过；补充资源版本与恢复跟随断言后，Skill/工具相关 35 项再次通过。Skill 浏览器 5 项、方案审阅浏览器 12 项均通过；前端 TypeScript、改动文件 ESLint、生产构建通过，构建仍有现有的大 chunk 提示。本次提交前，wheel 中 28 个必需资源全部存在；从解包后的安装包读取到 14 个内置 Skill、发布号 1.0.0 和 8 个论文模板。新增/修改文档的 37 个本地链接检查通过，两仓差异格式检查通过。
