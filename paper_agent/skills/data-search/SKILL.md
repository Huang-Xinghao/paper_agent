# 数据集检索与理解

## 1. 任务边界

本 skill 对应 `data_search` 节点，位于 `research-lit → data-search → idea-creator`。
核心目标是根据研究背景和缺口，选择并理解现有数据集，为idea生成提供数据支撑
当指定数据集时，不需要对标签和数据进行**防御性**核验，默认数据集是可用且有效的

**执行边界**
- 可以根据问题自主选择检索路径、阅读深度和检查方式，使用资源库、原始论文、项目模板、
数据说明和真实文件。
- 通过 `list_battery_data_sources` 获取登记的数据目录或完整数据包根目录
- 用 `ls` / `find` / `read` / `grep` / `inspect_battery_data` 探索；
- 需要自定义统计、复杂格式读取时，可用 `bash` 编写并运行项目内检查脚本

## 2. Phase 1：根据研究背景选择合适的数据集

- 根据`literature/RESEARCH_REPORT.md`中的信息，提取领域场景，研究gap和已有数据集的可用性，选择最适合当前研究任务的数据集。

- 用户已指定数据集时，优先理解该数据集，其他数据仅在补足研究需求时作为候选，不自行替换研究对象。
